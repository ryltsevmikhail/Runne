# Терминальный coding agent

**Decision.** Полноэкранный интерфейс встроен в Rust CLI. Runtime хранит сессии, сообщения, решения о разрешениях и результаты действий; интерфейс использует публичный runtime-client.

## Запуск и сессии

Из каталога проекта:

```console
runne
```

Явный выбор проекта или продолжение сессии:

```console
runne chat --project /absolute/path/to/project
runne chat --resume
```

**Decision.** `--resume` открывает выбор сохранённой сессии текущего проекта. UUID необязателен. В открытом интерфейсе F2 показывает сессии, `/new` начинает новую. При первом открытии `/register` регистрирует показанный каталог проекта и подтверждает доверие к нему. Открытие интерфейса не отправляет запрос провайдеру.

## Работа в терминале

| Действие | Клавиша |
|---|---|
| Отправить сообщение | Enter |
| Новая строка | Alt+Enter |
| Помощь | F1 |
| Сессии | F2 |
| Действия и вывод команд | F3 |
| Изменения файлов | F4 |
| Ожидающие разрешения | F5 |
| Запросить отмену | Ctrl+C |
| Завершить после проверки состояния задачи | Ctrl+Q |

**Decision.** Вставка многострочного текста не отправляет его автоматически. Изменение размера терминала сохраняет ввод. Разрешение выдаётся для показанного конкретного действия; отклонённое действие не исполняется.

## Возможности и границы

**Decision.** Профиль coding agent позволяет модели просматривать и искать файлы, читать, создавать и заменять их, запускать команды в каталоге проекта. Перед изменениями и командами пользователь видит запрос разрешения. Команды ограничены временем, выводом и областью проекта; сетевой доступ команд запрещён. Лимиты бюджета конечны. Ошибки, отмена и неизвестный результат не приравниваются к успешному выполнению.

**Decision.** CLI запускает собственный protected runtime и завершает его при штатном выходе. В Linux делегированная cgroup создаётся штатным systemd user scope из Rust. Этот режим требует установленных совместимых бинарников и принятой provider authority. Старый внешний daemon нельзя запускать одновременно для той же установки. Статус проверяется через аутентифицированный runtime внутри TUI; внешний `runne status` не получает доступ к protected runtime через экспорт секретного профиля.

**Observed.** Проверки этой разработки используют синтетический локальный провайдер. Они не подтверждают новый live-ответ DeepSeek или поддержку инструментов реальным endpoint. Фактический состав проверок и хеши установленной сборки фиксируются отдельно в отчёте поставки.
