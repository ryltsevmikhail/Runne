# Getting support

Runne is an actively developed open-source project. Community support is provided on a best-effort basis; there is no guaranteed response time or commercial support commitment.

- **Setup:** start with the [README](README.md) and [contribution guide](CONTRIBUTING.md).
- **Bugs:** search [existing issues](https://github.com/ryltsevmikhail/Runne/issues), then use the bug-report form. Include a minimal reproduction, commit/version, Linux distribution, toolchain versions, and sanitized error output.
- **Feature requests:** explain the problem and use case in the feature-request form. A request is not a commitment to implement it.
- **General questions:** open a concise issue with a descriptive title and the steps you have already tried.
- **Security:** follow the [private reporting instructions](SECURITY.md). Do not use public issues.
- **Conduct:** follow the [Code of conduct](CODE_OF_CONDUCT.md).

Do not share credentials, private project content, or unredacted runtime logs. Linux is the only active execution-node target; other platform code does not establish execution support. Provider accounts, billing, and credential revocation are handled by the relevant provider, not by this project.
